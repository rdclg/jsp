Develop an EJB-based shopping bill calculator that accepts product
price and quantity and calculates the total amount.
Technology: EJB Stateless Bean
Where to write: `src/java/ShoppingBillBean.java`
Easy explanation: The total amount is unit price multiplied by quantity.
Code
import javax.ejb.Stateless;
@Stateless
public class ShoppingBillBean {
    public double total(double price, int quantity) {
        if (price < 0 || quantity < 0) throw new IllegalArgumentException("Values cannot be negative");
        return price * quantity;
    }
}
Sample output: Price 50, quantity 4 -> Total = 200.0
How to run: Deploy and call `shoppingBillBean.total(50,4)`.
Viva question: How do you calculate a shopping total?
Viva answer: Price multiplied by quantity.
