Develop a JSP application that passes values from one page to another
and validates name, age, hobbies, email and gender.
Technology: JSP form validation
Where to write: `Web Pages/profileForm.jsp` and `Web Pages/profileResult.jsp`
Easy explanation: The first JSP collects values. The second JSP checks important fields and displays them. For real
applications, escape displayed input to avoid unsafe HTML.
Code
<!-- File: profileForm.jsp -->
<form action="profileResult.jsp" method="post">
  Name: <input name="name" required><br>
  Age: <input name="age" type="number" min="1" required><br>
  Hobbies: <input name="hobbies" required><br>
  Email: <input name="email" type="email" required><br>
  Gender: <select name="gender"><option>Female</option><option>Male</option><option>Other</option></select><br>
  <button>Submit</button>
</form>
