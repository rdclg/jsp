 Create a JSP application using JSTL to display a list of available books
with titles, authors and prices.
Technology: JSP + JSTL
Where to write: `Web Pages/books.jsp`; add JSTL 1.2 library
Easy explanation: The JSP stores two sample books in a list and JSTL loops through them to display a table.
Code
<!-- File: books.jsp. Add JSTL 1.2 library. -->
<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
<%@ page import="java.util.*" %>
<%
List<Map<String,Object>> books = new ArrayList<>();
Map<String,Object> b1=new HashMap<>(); b1.put("title","Java Basics"); b1.put("author","A. Kumar"); b1.put("price",250);
Map<String,Object> b2=new HashMap<>(); b2.put("title","Web Design"); b2.put("author","S. Rao"); b2.put("price",300);
books.add(b1); books.add(b2); request.setAttribute("books",books);
%>
<h2>Available Books</h2>
<table border="1"><tr><th>Title</th><th>Author</th><th>Price</th></tr>
<c:forEach var="b" items="${books}">
<tr><td><c:out value="${b.title}"/></td><td><c:out value="${b.author}"/></td><td><c:out value="${b.price}"/></td></tr>
</c:forEach></table>
Sample output: Java Basics | A. Kumar | 250
Web Design | S. Rao | 300
How to run: Run `books.jsp`.
Viva question: Which JSTL tag repeats items?
Viva answer: `c:forEach`
