Create a JSP page that accepts employee number, employee name and
salary, then inserts the record into an emp database table.
Technology: JSP + JDBC
Where to write: `Web Pages/empInsert.jsp`; shared `app.DB.java`; MySQL table `emp`
Easy explanation: The JSP inserts an employee row using PreparedStatement. The emp table and database helper must
exist first.
Code
<!-- File: empInsert.jsp. Create table emp(empno INT PRIMARY KEY, ename VARCHAR(80), salary DOUBLE). -->
<%@ page import="java.sql.*" %>
<% if ("POST".equalsIgnoreCase(request.getMethod())) {
    try (Connection c=app.DB.getConnection();
         PreparedStatement p=c.prepareStatement("INSERT INTO emp(empno,ename,salary) VALUES(?,?,?)")) {
        p.setInt(1,Integer.parseInt(request.getParameter("empno")));
        p.setString(2,request.getParameter("ename"));
        p.setDouble(3,Double.parseDouble(request.getParameter("salary")));
        p.executeUpdate(); out.println("Employee inserted");
    } catch(Exception e) { out.println("Error: "+e.getMessage()); }
} %>
<form method="post">Employee No: <input name="empno" type="number"><br>
Name: <input name="ename"><br>Salary: <input name="salary" type="number" step="0.01"><br>
<button>Save</button></form>
Sample output: Employee inserted
How to run: Create the table, configure `app.DB`, and open `empInsert.jsp`.
