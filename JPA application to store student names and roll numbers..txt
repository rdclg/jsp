: Create a JPA application to store student names and roll numbers.
Technology: JPA Entity + EJB service
Where to write: `src/java/Student.java` and `src/java/StudentBean.java`; configure `AppPU`
Easy explanation: A Student entity maps name and roll number to a database row.
Code
// File: Student.java
import javax.persistence.*;
@Entity
public class Student {
    @Id @GeneratedValue(strategy=GenerationType.AUTO) private Long id;
    private String name;
    private int rollNo;
    public Student() { }
    public Student(String n,int r) { name=n; rollNo=r; }
    public Long getId(){return id;}
    public String getName(){return name;}
    public int getRollNo(){return rollNo;}
}
// File: StudentBean.java
import java.util.*;
import javax.ejb.Stateless;
import javax.persistence.*;
@Stateless
public class StudentBean {
    @PersistenceContext(unitName="AppPU") private EntityManager em;
    public void save(String n,int r){ em.persist(new Student(n,r)); }
    public List<Student> all(){ return em.createQuery("SELECT s FROM Student s",Student.class).getResultList(); }
}
Sample output: Saved student: Riya, roll number 12.
How to run: Create `Student.java` and `StudentBean.java`; configure `AppPU`, then call save and all.

Viva answer: It is used to identify a student; it should be unique in the class
