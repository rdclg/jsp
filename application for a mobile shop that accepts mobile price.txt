 Create a Servlet application for a mobile shop that accepts mobile price
and discount percentage and calculates the final price.
Technology: Servlet
Where to write: src/java/MobileDiscountServlet.java
Easy explanation: The discount amount is price times discount percent divided by 100. The final price is original price minus
discount.
Code
import java.io.*;
import javax.servlet.*;
import javax.servlet.annotation.WebServlet;
import javax.servlet.http.*;
@WebServlet("/mobilediscount")
public class MobileDiscountServlet extends HttpServlet {
    protected void doGet(HttpServletRequest request, HttpServletResponse response)
            throws IOException {
        response.setContentType("text/html;charset=UTF-8");
        PrintWriter out = response.getWriter();
        out.println("<h2>Simple Form</h2>");
        out.println("<form method='post'>");
        out.println("<label>Mobile price: <input type='number' name='price' required></label><br>");
        out.println("<label>Discount percent: <input type='number' name='discount' required></label><br>");
        out.println("<button type='submit'>Submit</button></form>");
    }
    protected void doPost(HttpServletRequest request, HttpServletResponse response)
            throws IOException {
        response.setContentType("text/html;charset=UTF-8");
        PrintWriter out = response.getWriter();
        double price=Double.parseDouble(request.getParameter("price"));
        double d=Double.parseDouble(request.getParameter("discount"));
        if(price<0 || d<0 || d>100) { out.println("Enter a discount from 0 to 100"); return; }
        double finalPrice=price-(price*d/100.0);
        out.println("Discount amount = Rs. "+(price*d/100.0)+"<br>Final price = Rs. "+finalPrice);
    }
}
Sample output: Price 20000, discount 10 -> Discount amount 2000; Final price 18000
How to run: Open `/mobilediscount` and enter the price and percentage.
Viva question: What is the formula for discount amount?
Viva answer: Price x discount percentage / 100
