 Develop a visitor hit-count application using a Singleton Session Bean.
Technology: EJB Singleton
Where to write: `src/java/HitCounterBean.java`
Easy explanation: A singleton bean has one shared instance for the application, so its counter is shared among visitors.
Code
import javax.ejb.Singleton;
import javax.ejb.Startup;
import javax.ejb.Lock;
import javax.ejb.LockType;
@Singleton
@Startup
public class HitCounterBean {
    private int count = 0;
    @Lock(LockType.WRITE)
    public int visit() { return ++count; }
    public int getCount() { return count; }
}
// In a Servlet: @EJB HitCounterBean counter;
// Print: "Visitor hits = " + counter.visit();
Sample output: Visitor hits = 1
Next request: Visitor hits = 2
How to run: Deploy on Payara/GlassFish. Inject it using `@EJB` into a servlet and call `visit()` on each request.
Viva question: Why use @Singleton?
Viva answer: To share one bean instance across the application
